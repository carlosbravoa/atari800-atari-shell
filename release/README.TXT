ASH 1.3 - the Atari SHell›=========================›A Unix-style command line for the Atari 8-bit›that replaces the DOS menu.››ASH.ATR  boot disk: attach on D1: and boot›ASH.XEX  same shell as a loadable program››ls [-l] [path]   list a directory›cd path          d1: .. / games/x›cat file         show a text file›edit file        full-screen text editor›cp src dst       copy files›rm mv            delete, rename / move›mkdir rmdir      directories (MyDOS)›lock unlock      protect files›format dn:       erase a disk (DOS 2)›run file / name  load and run a .xex›df file xxd peek poke theme help››Type 'help' at the prompt for the rest.›Tab completes names; up/down recall›history; BREAK cancels; RESET returns.›
